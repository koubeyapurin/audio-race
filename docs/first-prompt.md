これはJPHACKS向けの**2人共同開発練習用**のゲームです。現段階では**実装しないでください**。まず要件を確認し、2人で安全かつ効率的に開発するための具体的な計画を日本語で提案してください。

## 開発者・制約
- 2人ともWindows + VS Code
- 2人ともClaude Code・Codex・Herdrを利用する予定
- 共同開発経験はまだない。片方はGitの基本経験あり
- 自分たちで大量のコードを書くよりAI駆動開発が中心
- 追加予算0円
- Herdrは2人とも使う予定だが、Herdr独自の機能がないと成り立たない計画にはしない
- 担当の振り分けはあなた（Claude Code）に考えてほしい。事前にどちらかの担当を固定しない

## 提案してほしいこと
1. ゲームのMVPを最短で完成させる技術スタック（候補比較と推奨理由）
2. 2人が並行して作業できる、具体的なタスク分解と依存関係
3. 各タスクの担当案・実装順・所要時間の概算・受け入れ条件
4. 重要モジュールの境界と入力／出力データの型の提案
5. Windows PowerShellでそのまま使える環境構築・GitHubブランチ・PR・レビュー・マージの具体的手順
6. 同じファイルの同時編集を避ける方法。Claude Code・Codex・Herdrの安全な使い分け
7. 最初に行う技術検証（音声のpitch/RMS/onset検出、地形生成の安定性など）
8. Git共同開発の練習を達成するために必須のPR・レビュー・統合テスト
9. リスク、失敗した場合の簡易実装案、完成までのチェックポイント

まずは、①前提に矛盾がないか ②最小の実装範囲 ③推奨構成 ④担当分担表 ⑤最初の3つのアクション、の順で提示してください。重大な不足情報があれば確認質問してください。
